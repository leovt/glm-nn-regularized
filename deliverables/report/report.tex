\begin{abstract}
This project investigates regularized hybrids of generalized linear models
and neural networks for insurance claim frequency pricing.
The proposed model trains a linear branch and a neural correction jointly,
with a penalty on the correction's dense-layer weights.
Saved notebook outputs for French motor insurance data show a test Poisson
deviance of 44.952 for a weakly penalised hybrid, compared with 47.179 for
the baseline generalized linear model and 44.955 for a frozen hybrid.
These descriptive results suggest that regularization can recover
baseline-like predictions, but do not establish improved interpretability
or a statistically significant advantage over the benchmarks.
The planned SHAP analysis remains outstanding.
\end{abstract}

\section{Introduction}
\subsection{Motivation and research question}
Generalized linear models (GLMs) provide an explicit additive structure
on the log-rate scale.
Feed-forward neural networks (FNNs) allow more flexible effects.
A combined actuarial neural network (CANN) adds a learned correction to
a fitted GLM \cite{aitools,nesting}.
This project asks whether joint training with asymmetric regularization
can retain predictive improvements while favouring a GLM-like structure.

\subsection{Contribution and scope}
The empirical contribution is a jointly trained GLM--neural network hybrid
and a regularization sweep on French motor third-party liability data.
The analysis concerns claim frequency only.
Synthetic data, severity modelling, LocalGLMnet and XGBoost are not included
in the available notebook results.
The distinction between the proposed design and its current implementation
is documented below.

\subsection{Statistical continuity between GLMs and neural networks}
Moving from a GLM to an FNN changes the predictor while retaining the
Poisson assumption, log link, exposure treatment and likelihood-based
evaluation used here.
This provides a direct connection with familiar actuarial modelling.
Greater predictor flexibility does not itself resolve questions about
the suitability of the Poisson assumption or calibration.

\subsection{Explainability and departure from GLM structure}
SHapley Additive exPlanations (SHAP) provide a framework for attributing
predictions to input features \cite{shap}.
Mayer, Meier and W\"uthrich discuss their actuarial use \cite{actuarialshap}.
The intended diagnostic compares per-covariate SHAP dependence plots with
GLM effects on the log-rate scale.
Departure from GLM structure is not itself a numerical measure of
explainability.
No SHAP results are stored in the project notebook.

\subsection{Feature construction}
The GLM uses driver-age groups, vehicle brand, fuel type, log population
density and ordinal area, yielding 19 encoded predictors plus an intercept.
Driver age 31--40 is the reference group.
Although preprocessing also constructs vehicle-power, vehicle-age and
bonus--malus variables, the fitted GLM formula does not use them.

The neural branch additionally uses vehicle age, bonus--malus, vehicle
power and region, and uses continuous rather than grouped driver age.
Vehicle age, driver age, bonus--malus and power are capped at 20, 90, 150
and 15 respectively and standardised.
Log density is rounded to two decimal places and standardised; area is
ordinally encoded and standardised.
Vehicle brand and region receive two-dimensional embeddings.
Preprocessors are fitted on the full learning sample.
Consequently, differences between neural models and the GLM reflect both
functional flexibility and access to additional predictors.

\section{Model specifications and estimation}
\subsection{Poisson frequency model}
All models use the same statistical model, a Poisson model with log link.
The difference lies in the specification of the linear predictor $\eta(x_i)$, which is a linear function for the GLM and a combination of linear and neural functions for the hybrids.

For claim count $Y_i$, exposure $e_i>0$ and predictors $x_i$, assume
\[
 Y_i\mid X_i=x_i\sim\operatorname{Poisson}(\mu_i),\qquad
 \mu_i=e_i r_i,\qquad r_i=\exp\{\eta(x_i)\}.
\]
Exposure enters the GLM as a log offset.
The neural models predict annualised rates and fit $Y_i/e_i$ with
exposure weights using the Keras Poisson loss.

\subsection{Implementing GLM in Keras}
A hybrid model introduces two implementation challenges.
Firstly, as the GLM parameters are to be re-trained together with the FNN,
the stochastic gradient descent must be implemented in a way that includes the GLM parameters in the gradient computation.

The GLM can be implemented as a single dense layer with exponential activation. For this experiment, the exponential activation
function was implemented in a separate layer, thus allowing the GLM implementation to be reused in the hybrid model.

The bigger second challenge is to make sure that the GLM parameters are estimated reasonably well by the stochastic gradient descent optimizer, and not drift away from the maximum likelihood estimates.
In order to achieve this, before training hybrid models, several experiments were conducted to train a GLM in Kersa, using NADAM stochastic gradient descent optimizer.

The results of these experiments are shown in table \ref{tab:comparison}, and show that the Keras GLM implementation with appropriate hyperparameter settings is stable, i.e. does not drift away from the maximum likelihood estimates.
However too small batch sized can lead to considerable drift away from the maximum likelyhood estimate on the training data, despite this being a global optimum on a convex function.

The following model calibration experiments were conducted:
\begin{itemize}
\item {GLM: maximum likelihood estimate using iteratively reweighted least squares, implemented in \texttt{statsmodels}.}
\item {Keras Control: Keras implementation of the GLM, parameters initialized with the maximum likelihood estimates, no training performed. (This test the correct representation of the model function in Keras.)}
\item {Keras Trained: Keras implementation of the GLM, parameters randomly initialized and trained using NADAM optimizer.}
\item {Keras Stability Test: Keras implementation of the GLM, parameters initialized with the maximum likelihood estimates and further trained using NADAM optimizer. (This tests whether stochastic gradient descent can drift away from the maximum likelihood estimates.)}
\end{itemize}

The experiments were conducted with and without a validation split, and with different batch sizes. In case of the randomly initialized models the best epoch was kept for final evaluation, in case of the drift tests the last epoch was kept.

The following table shows the results of the experiments, with the learning and test Poisson deviance, and the observed over expected claims ratio (O/E) on the test data.
Calibration is measured as the ratio of observed over expected claims, with a value of 1 indicating perfect calibration.

Close to the optimum, deviance is approximately quadratic in calibration error, the penalty for small calibration errors is therefore small.

In all cases the training and validation losses are similar, indicating no overfitting. This is likely due to the low dimensionality of the GLM.

For reserving often calibration is more important than discrimination, however for pricing well discriminated risks are important for risk selection and avoiding adverse selection.

\section{Modelling functions}

\subsection{GLM}
The reference GLM is defined as a linear predictor function followed by the inverse of the link function.
In the case of the Poisson GLM, the log link function is used, the canonical link for the Poisson distribution.

The log link function has the advantage that the resulting model is multiplicative, each input factor can be seen as contributing a multiplicative effect on the resulting claims rate.

For comparing the GLM with other models it is important not to neglect the role of input representation and prepocessing, often incorporating expert knowlegde and judgement.

\subsection{Feed-forward neural network (FNN)}
The FNN has three hidden layers of widths 20, 15 and ten with hyperbolic
tangent activations, followed by an exponential rate output.
The frozen CANN multiplies the fitted GLM rate by an exponential neural
correction, equivalently adding that correction on the log-rate scale.
The standalone FNN uses the same constructor with the GLM multiplier
replaced by one.

The feed-forward neural network (FNN) is a fully connected network with a specified architecture.
In this experiment, the architecture for the FNN is chosen identical in the FNN stand-alone, the CANN and the regularized hybrid model.
The architecture is taken from the \emph{AI Tools for Actuaries} repository, and consists of three hidden layers with widths 20, 15 and 10, with hyperbolic tangent activation functions, followed by an exponential output layer.
In figure \ref{fig:fnn}, the linear predictor of the FNN is illustrated without the exponential output layer.
The data flow of the FNN is shown, with the data preprocessing on the left, the three hidden layers in the middle, and the exponential output on the right.

Instead of one-hot dummy encoding the FNN uses a learned embedding, which is as a small neural network that maps the categorical input to a lower-dimensional representation.
The FNN is provided with more features than the GLM, representing less expert involvement in selectzion.

\section{Implementation}



\subsection{Jointly trained regularized hybrid}
With $z_i$ denoting the GLM design and $u_i$ the neural inputs, the
implemented predictor is
\[
 \eta(z_i,u_i)=z_i^\top\beta+g_\theta(u_i).
\]
The GLM coefficients initialise the linear branch.
The correction's final kernel is initialised to zero, so the initial
prediction equals the GLM prediction; the hidden layers are not all
initialised to zero.
Both branches are trainable.
The implemented objective is
\[
 L(\beta,\theta)=\frac{1}{n}\sum_{i=1}^n
 e_i\left[r_i-\frac{Y_i}{e_i}\log r_i\right]
 +\lambda\sum_{\ell\in\mathcal D}\lVert W_\ell\rVert_F^2,
\]
where $\mathcal D$ comprises the correction's hidden and output dense
layers.
The penalty excludes embeddings and hidden-layer biases; the correction
output has no bias.
This differs from the outline's proposed penalty on all correction
parameters and should not be described as full-parameter ridge shrinkage.
The linear branch is unpenalised.

\section{Experimental design and evaluation}
\subsection{Training and validation}
Neural runs use Nadam and seed 1234.
The principal FNN and CANN runs use 200 epochs and batches of 5,000;
the regularization sweep uses 200 epochs and batches of 50,000.
Ten percent of the learning sample is reserved through
\texttt{validation\_split=0.1} in these runs.
The callback restores the best validation-loss weights; its patience
equals the epoch budget, so it does not normally shorten training.
For penalised models, monitored validation loss includes the penalty.

This implementation differs from the outline's proposed 56/14/30 split.
Moreover, the initial GLM and preprocessing use the full learning sample,
including the neural validation subset.
That subset is therefore not independent of all fitting steps.
Reported learning-sample metrics include the validation observations.

\subsection{Performance measures}
For observed rates $q_i=Y_i/e_i$, the reported score is
\[
 D_{100}=\frac{200}{\sum_i e_i}\sum_i e_i
 \left[q_i\log\left(\frac{q_i}{r_i}\right)-q_i+r_i\right],
\]
with $0\log(0/r_i)=0$.
This is 100 times the exposure-weighted mean Poisson deviance of rates,
not the unweighted mean deviance of counts.
Aggregate calibration is reported as observed divided by expected claims,
$\sum_iY_i/\sum_i e_i r_i$ (O/E).
A value of one denotes aggregate balance, without implying subgroup
calibration.
Gini indices and lift curves were proposed but are not present in the
saved outputs.

\section{Discussion and real-world applicability}
\subsection{Interpretation of the findings}
The current results support a predictive transition between a flexible
hybrid and a baseline-like model as regularization increases.
They do not show that linear effects are correctly allocated to the
linear branch or that regularization guarantees an interpretable tariff.
Because the branches can both represent some simple effects, their
decomposition is not uniquely determined by predictive fit alone.

\subsection{Frozen coefficients and total fitted effects}
Freezing the CANN's GLM coefficients preserves a reference component,
but those coefficients need not represent the complete fitted effects:
the neural correction may also capture linear effects.
Joint training permits coefficient adaptation, yet a penalty does not
guarantee an exclusively nonlinear correction.
Interpretation should therefore consider the combined predictor and
both branches rather than reading GLM coefficients in isolation.

\subsection{Calibration along the regularization path}
At $\lambda=0.0001$, test O/E is 1.0116 with deviance 45.105;
at $\lambda=0.001$, O/E improves to 0.9974 while deviance worsens to 45.727.
Aggregate balance and individual predictive fit therefore need separate
assessment.
Deviance is not a pure discrimination measure, and similar learning and
test scores do not establish stability across samples or random seeds.
Segment-level calibration remains an additional requirement.

\subsection{Limitations and robustness}
The main limitations are unequal feature access, different batch sizes,
validation reuse in initial fitting and preprocessing, incomplete penalty
coverage and a single seed and supplied test split.
Regularized validation losses also combine fit and penalty rather than
providing a common unpenalised selection score across $\lambda$ values.
Repeated seeds, comparable feature sets and independent model selection
would strengthen the comparison.
The saved outputs require a clean execution and environment record before
final submission.

\subsection{Implications for insurance pricing}
A regularization path could help compare predictive gains with the
complexity of corrections to a familiar tariff structure.
Practical use would additionally require subgroup calibration, stability
checks, documentation of feature effects and review of the resulting
pricing decisions.
Aggregate O/E and Poisson deviance alone do not establish deployment
readiness.

\subsection{Modelling choices and development effort}
Neural modelling exposes choices about embeddings, architecture,
initialisation, optimisation and regularization.
These choices interact, making development and validation effort part
of the practical comparison alongside predictive performance.
Possible extensions include spline-based age effects, learned knots or
thresholds and smoothness penalties.
They illustrate a continuum between constrained actuarial predictors
and flexible networks, but are not experiments established by the
current notebook.

\section{Conclusion}
The implemented hybrid provides a tunable penalty on neural dense-layer
weights while allowing the GLM branch to adapt.
Available results show improved test deviance over the selected GLM
baseline at weak penalties and baseline-like performance at stronger
penalties.
The central claim about departure from GLM structure remains open until
the planned structural diagnostics are completed.

specialized GLM optimizer in `statsmodels` to the general-purpose optimizers in `tensorflow`.

Using the baseline model from [AI tools for actuaries, ch 03], we first reproduce the GLM calibration in statsmodels

\begin{itemize}
    \item Reproduce GLM results in statsmodels
    \item Define a tensorflow model with the same architecture and loss function initialize it to the GLM weights and verify the inference. (ensuring that model spec and data encoding is correct and that weights are correctly transformed from GLM to tensorflow)
    \item Train the tensorflow model using initialization from the GLM weights and verify that the optimizer does not depart from the optimum result.
    \item Train the tensorflow model using random initialization and verify that the optimizer converges to the same solution.
\end{itemize}

Two main sources of error have been identified: 
\begin{itemize}
    \item Small batch sizes introduce jitter, even when starting from optimal solution.
    \item Splitting the training data further into fitting and validation will find the optimum on the fitting datatset and not on the whole training data set.
\end{itemize}
